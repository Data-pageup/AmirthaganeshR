Projects

Live · Multi-agent
GoAnywhere AI

A multi-agent travel planner built on LangGraph. Flight, Hotel, Itinerary and Final Response agents share state to turn one natural-language request into flights, hotels, a day-by-day plan and a budget. An input guardrail blocks non-travel requests before any API or LLM call, and PostgreSQL checkpointing gives it persistent memory so each trip's state survives across sessions.

💡 Insight

LangGraph's PostgresSaver checkpoints every run to PostgreSQL under a thread ID, so a conversation resumes where it left off instead of starting over. The guardrail runs first, so off-topic requests never trigger paid tool or LLM calls.

LangGraph FastAPI PostgreSQL LangSmith

A Tamil language model built end to end in PyTorch: a custom 32K BPE tokenizer, a decoder-only Transformer (6 layers, 384 hidden, 6 heads), pretraining on about 58M tokens from 100K documents, and a small SFT run. Weights and tokenizer are on Hugging Face.
